# Plot the map of Germany

Plots the map of Germany.

## Usage

``` r
eatMap(
  data,
  config,
  lang = "de",
  width = NULL,
  height = NULL,
  elementId = NULL
)
```

## Arguments

- data:

  Data frame. Data to be displayed.

- config:

  List. Configuration object for the display.

- lang:

  String, "de" or "en"

- width:

  Character. Width of the app.

- height:

  Character. Height of the app.

- elementId:

  Character. Id of the app.
